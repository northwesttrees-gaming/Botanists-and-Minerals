# Botanists and Minerals
This MCreator mod adds several new crops to the game that can produce raw products. These reaw products can be refined using a number of custom crafting stations. Each crop is for a specific mineral resource.

## Balance Comes First
This mod has several functions in place to make sure that ores can't easily be obtained and produce mass amounts of ore quickly.

- Seeds have a 1 in 1000 chance of dropping when ore blocks are mined.
- There is just over a 5 minute period for processing.
- Rarer ores like Diamond will by proxy be more rare to obtain seeds for due to ore distribution.
- Crops only give one seed back when the plant is harvest so it's not  possible to ramp up farm sizes without mining more of that ore.

## Features
In addition the mod has several feature that makes it stand out.

- Rare seeds drop when mining ores.
- Seeds can be planted on farmland.
- Seeds require light to place/grow.
- Bees can pollenate plants if they have nectar.
- Plants can get washed away by water allowing automation farming methods.
- Raw crop can be turned into dust.
- Dust can be turned into compacted dust.
- Compacted dust can be smelted for actual resource (requires 9 dust to craft one block)
- Processing can be automated using hoppers and redstone systems.
- Rarer resources like Diamonds, Nether Debris naturally are harder to get seeds due to lower generation numbers of ore.
- Uses Tags so cross mod compatible.

## Machines
Raw crop products  can be processed by the machines below in the following order.

1. Grindstones (Andesite, Diorite, Granite, and Stone)
2. Compactor
3. Smelter (Andesite, Diorite, Granite, and Stone)

## Compacted Blocks
Compacted blocks allow for new block decorations, nice for different floors or walls. These blocks have gravity and there for will work in some redstone machines.
